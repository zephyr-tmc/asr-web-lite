## Implementation decisions

- 桌面个人使用，中文 UI，沿用 macOS 和 Windows 的现有入口。服务仍默认只监听回环地址。
- 首个可插拔适配器为 Chat Completions 兼容 HTTP JSON 接口：用户填写完整服务地址或 /v1 基址、模型名称和可选密钥；本机无需密钥的兼容服务亦可。其它服务协议作为后续适配器，不声称全部厂商兼容。
- 元数据、文稿版本与生成成果用 SQLite（标准库）；不需要配置数据库服务。旧 tasks.json 保持兼容。
- 密钥仅存在服务进程内存，重启重新填写；连接元数据持久化，接口不返回密钥。更换地址不沿用原服务密钥。
- 生成最长 32,000 字符；超过时明确提示分段，避免静默截断。取消停止本地等待与结果写入，上游服务可能仍计费处理。
- ASR 保存时间段 sidecar；导入旧 TXT 没有时间戳时不编造时间位置。
- 后端和工作室资源由两平台共用；更新 Windows 打包路径。
